MasterBot Proxy API (1.0.0)

Download OpenAPI specification:

Backend API consumed by the MasterBot web app and the MasterBot Bridge Chrome extension. Hosted on Vercel as serverless functions.

The API is mostly a proxy in front of three upstreams: MAPRO (https://app.mapro.us), gateaccess.net, and portal.proptia.com. A small admin surface manages the MAPRO session cookie stored in Upstash Redis (the only piece of stateful data the API holds).

Auth

All endpoints (except the public GET /api/proptia/add-visitor health probe) require an Authorization: Bearer <token> header. Two schemes are accepted:

  • firebaseBearer — a Firebase ID token. Verified with firebase-admin. The decoded email is used for the admin allowlist on admin routes.
  • bridgeOrFirebaseBearer — same as above, but the literal value of the BRIDGE_SECRET env var is also accepted. Used by the Chrome extension's background-script bridge.

Admin routes additionally require the caller's email to appear in the ADMIN_EMAILS env var (comma-separated). Bridge callers bypass the allowlist on /api/admin/mapro-test but NOT on /api/admin/mapro-cookie.

CORS

Allowed origins:

  • https://alissonrochah.github.io
  • http://localhost:4000
  • http://127.0.0.1:4000

Methods: GET, POST, OPTIONS. Headers: Authorization, Content-Type.

Errors

All 4xx/5xx responses share the envelope { "error": "<message>" }. Some errors include extra context fields (e.g. booking, ulid, stage, v).

The dedicated 503 MAPRO_NOT_LOGGED_IN code means the cookie stored in Upstash has expired or is missing; the frontend must trigger POST /api/admin/mapro-cookie with a fresh cookie to recover.

mapro

MAPRO-backed endpoints (units, reservations, inbox, messaging).

Bulk-resolve addresses/codes/resort to MAPRO reservations

Resolves a list of addresses, Airbnb confirmation codes, or a whole resort to MAPRO units, then queries MAPRO's calendar for reservations matching the mode (checkin = check-ins on the day; inhouse = currently in-house) on date. Results are split into Airbnb / non-Airbnb / no-reservation / not-found buckets.

Max 300 items per call.

Default: "checkin"

Required when source=addresses. "address" header row is filtered out.

Required when source=codes.

List MAPRO units with extras and (optionally) Airbnb channel links

Returns every MAPRO house with BBQ flag, pool-heater tier (35/75), resort address, and optionally Airbnb Red/Green channel URLs.

Without channels=1 the call is fast. With channels=1 it fetches the channel page for every unit and can take 10–25s.

Cache: public, s-maxage=120, stale-while-revalidate=300.
